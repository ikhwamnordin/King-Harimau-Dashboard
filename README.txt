This is a mobile-first PWA-ready static dashboard.

To make it a real Android home-screen app:
1. Upload this folder to an HTTPS static host (GitHub Pages, Netlify, Vercel, Cloudflare Pages, etc.).
2. Open the HTTPS URL in Chrome on Android.
3. Chrome menu > Add to Home screen / Install app.
